# dnd5e Text Parser

Shared library that parses dnd5e stat block and item text (English and French) into dnd5e 6 data.

Module Foundry VTT v14 pour le système dnd5e 6.x.

## Installation

Dans Foundry : **Add-on Modules → Install Module**, puis coller l'adresse du manifeste :

```
https://github.com/rydka/dnd5e-text-parser/releases/latest/download/module.json
```

## Utilisation

À compléter.

## Développement

```
npm install
npm test        # tests unitaires
npm run lint
```
